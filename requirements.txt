# Offline / Electron dependency set.

# djangoexact/requirements.txt is the source of truth: it is what both
# deploy/Dockerfile.web_service and deploy/Dockerfile.computation_job install,
# and what deploy.yaml and deploy-cloudrun.yaml install in CI. This file
# includes it rather than repeating its pins, so the offline environment cannot
# drift away from production again.
#
# It previously did repeat them, as a flattened pip-freeze snapshot pinning
# Django==4.2.1, while djangoexact/requirements.txt had moved on to
# Django==5.2.17. Nothing surfaced the split until api/models.py started using
# UniqueConstraint(nulls_distinct=...), which needs Django 5.0+, and seeding the
# bundled database began failing at django.setup(). The snapshot had also
# accumulated dead entries by then (pyrebase4, gcloud, oauth2client and
# google-cloud-firestore had no import sites left anywhere in djangoexact/).
#
# Installed by electron/scripts/setup-standalone-python.{sh,ps1} and
# electron/scripts/setup-python-env.{sh,bat}, all four of which read this path.

-r djangoexact/requirements.txt
